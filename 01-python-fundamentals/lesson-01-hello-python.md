# Lesson 01 — Your First Python Program

## Objective
By the end, you should be able to run Python, explain what `print()` does, store a value in a variable and change the output yourself.

## Where to run it
On Android, open [Google Colab](https://colab.research.google.com/), create a notebook, type the code into a code cell and press the play button.

## Example
```python
print("Hello, Nexforge 11!")
name = "Learner"
print("Welcome,", name)
```

- `print()` displays information.
- A **string** is text between quotation marks.
- A **variable** stores a value under a name.

## Your turn — do not copy the example unchanged
1. Display a welcome message of your own.
2. Create a variable named `project_name` containing `"Nexforge 11"`.
3. Display the words `My project is` followed by that variable.
4. Change the variable and run the cell again. Observe what changes.

## Challenge
Create a second variable called `hours_per_week` with the number `7`. Print a sentence that includes both variables.
