# Nexforge 11 — Learning Roadmap

**Goal:** progress from complete beginner to independently building Python software, useful automation and AI applications.

**Suggested pace:** 6–8 hours per week. Progress by demonstrated understanding, not deadlines.

| Stage | Focus | Evidence of progress |
|---|---|---|
| 1 | Python fundamentals | Write small programs using variables, input, decisions, loops and functions |
| 2 | Independent Python | Build, debug and test a small command-line project |
| 3 | Git and GitHub | Track changes and explain commits, branches and pull requests |
| 4 | Data and automation | Read files, work with APIs and automate a real task |
| 5 | Maths and machine learning | Understand data, model evaluation and basic ML workflows |
| 6 | AI applications | Build an application using an AI API responsibly |
| 7 | AI agents | Create a tool-using workflow with safeguards and evaluation |
| 8 | Applied engineering | Improve reliability, tests, deployment and documentation |
| 9 | Capstone | Plan, build, document and demonstrate a portfolio project |

## Learning method
Observe → Diagnose → Plan → Teach → Practise → Assess → Record → Adapt.

Every lesson should include an explanation, a worked example, an independent exercise, feedback and a short reflection. Never treat reading alone as mastery.
